# Mini Arcade Game Suite

## Description

Mini Arcade Game Suite is a simple Python-based terminal game project that includes multiple fun mini games for users to play.

## Games Included

* Number Guessing Game
* Rock Paper Scissors
* Quiz Game

## Features

* Menu-driven program
* Beginner-friendly Python project
* Simple and interactive gameplay
* Input validation for better user experience

## Technologies Used

* Python 3

## How to Run

1. Download or clone the project
2. Open the project folder
3. Run the following command:

```bash
python mini_arcade.py
```
